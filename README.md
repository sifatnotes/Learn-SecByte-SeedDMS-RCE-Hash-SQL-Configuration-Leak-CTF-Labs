# Learn SecByte SeedDMS, RCE, Hash, SQL & Configuration Leak CTF Labs

A focused collection of hands-on cybersecurity and CTF labs from Learn SecByte covering SeedDMS discovery, authentication, administrative access, shell drops, remote code execution, hash security, MySQL enumeration, configuration leaks, and source-code analysis.

These labs are useful for cybersecurity students, CTF players, penetration testers, SOC analysts, and security learners developing practical web application and vulnerability-analysis skills.

## Introduction

Web application assessments often involve multiple layers: application discovery, authentication, source-code analysis, credential and hash security, database enumeration, and controlled exploitation.

This repository organizes Learn SecByte labs around SeedDMS security, RCE, hash-related attack paths, MySQL investigation, configuration exposure, and JavaScript source-code analysis.

## Learning Path

A practical sequence for this collection is:

1. Begin with **SeedDMS Discovery** and **SeedVault Slipstream** for application reconnaissance.
2. Continue with **JS Trail Source Code Secrets** and **Config Leak Drop** to identify information-disclosure risks.
3. Study **SeedDMS Admin Unlock** for authentication and administrative-access concepts.
4. Explore **Hash Reset Heist**, **Hash Hijack**, and **Seeded Secrets** for credential and secret-security scenarios.
5. Use **SQL Sleuth MySQL Bones** to practice database investigation.
6. Progress to **SeedDMS Shadow Seed** and **SeedDMS Shell Drop** for deeper application-security exercises.
7. Finish with **SeedDMS Authenticated RCE** to study an authenticated remote-code-execution scenario in a controlled lab.

## How to Use the Labs

- Use all exercises only in authorized and controlled environments.
- Begin with application and service reconnaissance.
- Inspect source code and configuration files for accidental information disclosure.
- Treat all discovered credentials, hashes, and secrets as lab-only data.
- Study authentication boundaries before testing administrative access.
- Analyze SQL and database behavior within the provided environment.
- Practice RCE and shell techniques only against authorized lab targets.
- Document vulnerabilities, evidence, and potential defensive mitigations.
- Never reuse discovered lab credentials against real systems.
